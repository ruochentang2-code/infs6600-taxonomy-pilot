# Open configuration points

These open configuration decisions do not block the INFS6600 v2 pilot.

1. Should the positive threshold remain 3.0?
2. Should high confidence remain 5.0, and what empirical rationale should define it?
3. Should Career readiness remain at the provisional weight of 2.0?
4. Should an administrative `Case studies` assessment label remain a review-only signal at weight 2.0?

Until these points are validated, the pipeline keeps the thresholds configurable and labels them provisional.
